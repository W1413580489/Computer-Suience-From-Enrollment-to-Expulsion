### 打印

### 学校邮箱

网络与教育技术中心为在校师生提供免费的电子邮箱服务，其中学生邮箱即为“学子邮”（@stu20XX.jnu.edu.cn，其中20XX，为学生入学年份），学生如需申请该邮箱，需通过[https://mynet.jnu.edu.cn/app/login](https://mynet.jnu.edu.cn/app/login) 登录“校园网用户助服务平台” ，选择业务办理，并选择学子邮，确认邮箱名称和密码，并提交申请

# 💻 开发工具包

### GitHub Student Developer Pack

用学校邮箱注册 GitHub 账号，然后去 [GitHub Education](https://education.github.com/pack) 申请学生包。审核一般 1-3 天。

通过之后你能免费拿到：

| 工具 |  |
|-|-|
| GitHub Copilot（AI 编程助手） | 学生包中包含 GitHub Copilot 的免费访问权限 |
| JetBrains 全家桶（IntelliJ / PyCharm / WebStorm 等） | 可免费使用专业版 IDE |
| Namecheap 域名 | 可免费获得一个 `.me` 域名的一年注册权 |
| DigitalOcean \$200 额度 | 通常有效期为一年 |
| Notion Plus（个人 Pro 计划） | 可以升级到 Notion 的免费教育版 |
| Canva Pro | 学生包包含 Canva Pro 的免费访问权限 |
| Termius（SSH 客户端） | 提供 SSH 客户端的免费访问 |

完整列表见 [GitHub Education 官网](https://education.github.com/pack)，上面只是一部分。完整教程请参考：

https://cloud.tencent.com/developer/article/2639705

> *在申请Github学生认证的全程都都需要保持给予Github定位权限（必须）*建议在学校附近进行定位（Windows等可以使用虚拟定位）并使用校园网环境。如无必要不建议使用代理。

<callout emoji="❓">
**但是根据外网信息，GitHub Copilot Student似乎目前暂停用于新注册**
</callout>

### JetBrains 全家桶

申请完 GitHub Student Pack 之后，用 GitHub 账号登录 JetBrains 官网，就能免费使用所有 IDE 的专业版。包括：

- **IntelliJ IDEA Ultimate** — Java/Spring Boot 开发
- **PyCharm Professional** — Python/Django 开发
- **WebStorm** — 前端/Node.js 开发
- **CLion** — C/C++ 开发
- **DataGrip** — 数据库管理

比 VS Code 重，但 Java/Python 项目体验好很多。比用 Dev-C++ 强一百倍,但是大一C语言课你就老老实实用吧...

### VS Code

免费开源，插件生态最丰富。前端、Python、Markdown 写文档都行。如果你不知道用什么 IDE，先装 VS Code。

推荐插件：

- **GitHub Copilot** — 代码补全
- **Prettier** — 代码格式化
- **Markdown Preview Enhanced** — Markdown 预览
- **Remote - SSH** — 远程连接服务器
- **Thunder Client** — API 测试（Postman 替代品）

<callout emoji="❗">
以上资源未必刚需，各位自行研究，且访问一些外网大部分时候需要梯子，受限于法律原因，请私下向你的学长/我询问
</callout>

# 📚 学术资源

> **知网是付费的，但你有别的办法。**

### 论文

- **Google Scholar** — 搜论文首选，用学校 VPN 可以访问部分付费论文
- **知网（CNKI）** — 学校图书馆买了部分库，通过学校访问可以免费下载
- **arXiv** — 计算机领域预印本，免费，最新的 ML/CV/NLP 论文都在上面
- **Sci-Hub** — 输入论文 DOI 就能下载 PDF。域名经常变，Google 搜"Sci-Hub 最新网址"
- **Semantic Scholar** — 免费学术搜索引擎，AI 驱动

### 电子书

- **Z-Library** — 全球最大的电子书库。域名经常变，搜"Z-Library 最新入口"
- **Library Genesis** — 教材和学术书籍
- **Anna's Archive** — Z-Lib + LibGen 的聚合搜索
