# 数据来源与使用说明

## 一、数据来源名称

本项目 `data/poems.json` 中的古诗词数据，参考自公开诗词数据集项目 **chinese-poetry**。

- 上游仓库链接：<https://github.com/chinese-poetry/chinese-poetry>
- 该项目在其仓库中标注为 **MIT License**，并说明其数据"来源于互联网"。
- 本课程仅从其中抽取了**小规模子集**，用于静态页面的教学演示。

## 二、数据用途说明

- 本数据**仅用于本课程的教学演示**（练习读取 JSON、搜索、筛选、渲染详情与统计）。
- 未用于任何商业用途，也未大规模分发。
- 抽取的内容规模很小，属于教学样例性质，不代表完整的上游数据集。

## 三、本课程对数据的简化说明

上游 chinese-poetry 的数据结构较复杂（按朝代、作者、体裁分成大量文件，字段也较多）。为了方便零基础同学理解，本课程做了如下简化：

- 把分散的数据**合并成一个 JSON 数组**，放在 `data/poems.json`。
- 把复杂字段**压缩成 6 个简单字段**：

  | 本课程字段 | 含义 |
  | --- | --- |
  | `id` | 唯一编号，如 `p001` |
  | `title` | 作品标题 |
  | `author` | 作者 |
  | `dynasty` | 朝代 |
  | `content` | 正文（按"行"组成的数组） |
  | `tags` | 标签，1–3 个（本课程额外整理，便于练习筛选） |

- 对正文按原诗断句拆成多行，方便页面排版。
- 只保留了少量作品，并非该数据集的全貌。

因此，本文件中的结构**不代表上游的原始结构**，只是课程用的简化版本。

## 四、学生替换数据时，应如何写新的来源说明

如果你把 `data/poems.json` 换成自己收集或其它来源的数据，请**同步更新本文件**，至少说明清楚：

1. **数据来源名称**：数据来自哪个网站、仓库、书籍或数据库。
2. **来源链接**：如果来自网络，写上可访问的链接。
3. **许可情况**：该来源标注的许可协议（如 CC、MIT、公有领域等）；如果来源没有明确许可，请如实写明"来源未标注许可"。
4. **用途与范围**：说明数据用于什么用途、抽取了多少、是否只用于学习演示。
5. **你做了哪些整理**：是否做了简化、拆行、加标签、纠错等改动。
6. **使用限制**：如果原来源对使用有限制，请一并写明。

> 注意：不要想当然地认为"所有古诗词天然属于任意许可"。不同来源的数据可能带有不同的许可与使用条款，请以该来源的官方说明为准；不确定时，宜保守使用并主动注明来源。
