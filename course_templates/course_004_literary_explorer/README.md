# 古典文学探索器

一个用来练习"网页作品管理"的极简静态小站：读取 `data/poems.json` 里的古诗词数据，支持关键词搜索、朝代筛选、点击查看详情和实时统计。

它没有任何后端、数据库、API Key 或第三方框架，只用原生 HTML + CSS + JavaScript，可以离线运行，很适合作为课程起始模板。

## 运行方法

**推荐方式：用本地服务器打开。**

1. 在本项目目录下打开终端，执行：

   ```bash
   python -m http.server 8000
   ```

2. 在浏览器访问：

   ```
   http://127.0.0.1:8000
   ```

**为什么不要直接双击 `index.html`？**

因为 `app.js` 需要用 `fetch` 去读取 `data/poems.json`。浏览器出于本地安全策略，会阻止通过 `file://` 方式打开的页面读取本地 JSON 文件，双击打开会看到"数据加载失败"的提示。用本地服务器（`http://127.0.0.1`）访问就没有这个问题。

## 目录结构与各文件职责

```
course_004_literary_explorer/
├─ index.html          页面结构：搜索框、朝代下拉、列表区、详情区、统计区
├─ style.css           样式：布局、间距、边框、简单配色
├─ app.js              逻辑：加载数据、搜索筛选、点击详情、统计计算
├─ data/
│   └─ poems.json      数据：唯一的作品数据源
├─ README.md           说明文档（本文件）
└─ DATA_SOURCE.md      数据来源与使用说明
```

- **index.html 管结构**：只放骨架，不写任何具体诗词内容。
- **style.css 管样式**：只负责好看与可读。
- **app.js 管逻辑**：只负责"怎么显示"，不写死具体哪首作品。
- **data/poems.json 管数据**：负责"显示什么"。**只要改这个文件，页面内容就会变，不用改 app.js。**

## 当前数据说明

- 数据文件：`data/poems.json`
- 是一个 JSON 数组，目前收录 72 首中国古典诗词（公版）。
- 每条记录的字段：

  | 字段 | 含义 |
  | --- | --- |
  | `id` | 唯一编号，如 `p001` |
  | `title` | 作品标题 |
  | `author` | 作者 |
  | `dynasty` | 朝代（用于筛选） |
  | `content` | 正文，按"行"组成的数组 |
  | `tags` | 标签，1–3 个 |

- 朝代覆盖唐、宋、元、明、清，方便演示"朝代筛选"。

## 后续可以做的任务方向

- **改数据**：在 `data/poems.json` 里增删作品、修改标题作者、调整标签。只改 JSON，页面就会跟着变。
- **加搜索**：给搜索加上"按标签搜索"或"按正文搜索"，或给关键词高亮。
- **加详情**：在详情区增加"作者简介""相似作品推荐"等模块。
- **加统计**：增加"标签分布""单首诗平均句数"，或把朝代分布做成图表。
