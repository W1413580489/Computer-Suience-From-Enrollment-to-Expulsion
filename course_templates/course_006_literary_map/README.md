# 文学地图（学生起始项目模板）

这是一个给零基础同学使用的**纯静态**网页起始模板，用来做一张“文学地图”：
左边是一张 **SVG 示意地图**，右边是**故事面板**，点地图上的地点就能看到对应的故事，
也可以用“上一个 / 下一个”按顺序浏览全部故事。

- 只用原生 HTML + CSS + JavaScript，不引入任何框架、库或外部字体。
- 没有任何 API Key、没有后端、没有数据库，也不需要安装任何东西。
- 本课程**不是 GIS 课程**：地图只是一张示意图，坐标是示意坐标，**不使用经纬度，也不接入任何真实地图服务**。

---

## 一、如何运行（重要）

**不要直接双击 `index.html`。** 直接双击打开时，浏览器会因为安全限制而无法读取
`data` 文件夹里的 JSON 数据，页面会显示“数据加载失败”。

正确做法是在本项目的文件夹里打开命令行，执行：

```bash
python -m http.server 8000
```

然后在浏览器访问：

```
http://127.0.0.1:8000
```

（结束运行：在命令行按 `Ctrl + C`。）

## 二、目录结构

```
course_006_literary_map/
├─ index.html        页面骨架：标题、地图容器、故事面板、上一个/下一个按钮
├─ style.css         样式：布局、地点节点、名称文字、路线、高亮效果
├─ app.js            逻辑：读取 JSON、画地图、点击地点、顺序浏览故事
├─ data/
│  ├─ places.json    地点数据（“显示什么”的地点部分）
│  └─ stories.json   故事数据（“显示什么”的故事部分）
├─ README.md         本说明文件
└─ DATA_SOURCE.md    数据来源与整理说明
```

各文件职责的简单分工：

- **`places.json`**：存放地点。每个地点有 `id`、`name`、示意坐标 `x`/`y`，以及 `summary`（简介）。
- **`stories.json`**：存放故事。每条故事用 `place_id` 关联到某个地点，用 `order` 决定先后顺序。
- **`app.js`**：只管“怎么显示”。它从上面两个 JSON 读取数据来画图和显示文字。
  **所以：只改 JSON、不改 `app.js`，地图和故事内容就会跟着变。**

### 数据字段说明

`data/places.json`（地点，共 8 个）：

| 字段 | 含义 |
| --- | --- |
| `id` | 地点编号，如 `place01` |
| `name` | 地点名称，如“绍兴” |
| `x`、`y` | **示意坐标**（不是经纬度），分布在 SVG 的 `0 0 900 520` 范围里 |
| `summary` | 地点简介 |

`data/stories.json`（故事，共 12 条）：

| 字段 | 含义 |
| --- | --- |
| `id` | 故事编号，如 `story01` |
| `order` | 叙事顺序，为 1…12，且不重复 |
| `place_id` | 关联的地点编号，必须能在 `places.json` 中找到 |
| `time` | 时间标签 |
| `title` | 事件标题 |
| `body` | 故事正文 |

## 三、当前数据说明（请务必阅读）

本模板的示例数据是一条 **“鲁迅文学行迹”路线**：8 个地点、12 条故事，
地点名称（绍兴、南京、日本·东京、日本·仙台、北京、厦门、广州、上海）与
故事内容都围绕鲁迅的生平与创作路线整理，`order` 按时间先后排列。

这些文字只是**课程提供的示例素材**，用于演示“地点 + 故事”的数据结构与交互效果：

- `places.json` 的 `summary` 是地点简介。
- `stories.json` 的 `time` / `title` / `body` 是每条故事的时间标签、标题与正文。
- 示例内容取自通行的鲁迅生平记述，整理方式与来源见 [DATA_SOURCE.md](DATA_SOURCE.md)。
  它**只用于教学演示**，不作为学术引用依据；如需引用，请回到原始文献核对。

你可以在后续任务中把这份示例整体替换成自己想讲的文学故事（见第四节第 4 条）。

## 四、后续任务方向

1. **地点点击**：点击地图上的地点，故事面板显示该地点的故事（一个地点有多条时，先显示 `order` 最小的一条）。
2. **故事展示**：故事面板显示时间 / 标题 / 正文，以及当前地点名称。
3. **顺序浏览**：用“上一个 / 下一个”按 `order` 在全部故事间切换，并同步高亮地图上的地点。
4. **替换故事**：把 `stories.json` 里的示例故事，换成自己想讲的文学故事（可参考示例的字段格式）。
5. **新增地点**：在 `places.json` 里增加地点（记得给一个不重复的 `id` 和合适的示意坐标），
   并在 `stories.json` 里用 `place_id` 关联它。
