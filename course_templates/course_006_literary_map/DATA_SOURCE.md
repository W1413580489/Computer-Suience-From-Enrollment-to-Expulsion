# 数据来源与整理说明

本文件说明“文学地图”模板里数据的来源、用途和简化方式，并告诉同学在替换成
自己的文学故事时，应该怎样补充来源说明。

---

## 一、数据来源与整理方式

1. **主题。**
   示例数据是一条 **“鲁迅文学行迹”路线**，地点名称与故事内容围绕鲁迅（周树人，1881—1936）
   的生平与创作路线整理，用于演示“地点节点 + 故事关联”的数据结构。

2. **内容来源。**
   `places.json` 的 `summary`、`stories.json` 的 `time` / `title` / `body` 均依据通行的
   鲁迅生平记述（如《鲁迅年谱》、《鲁迅全集》相关注释、各地鲁迅纪念馆等公开资料）概括整理。
   正文为课程作者概括的**叙述性文字**，不直接引用原文，也不包含虚构的对白或细节。

3. **顺序与坐标。**
   - `order` 为 1…12，按鲁迅生平的时间先后排列，用于页面上的“上一个 / 下一个”浏览。
     同一地点出现多条故事，是因为鲁迅在不同时期多次到访或长期居住于该地。
   - `x` / `y` 是 SVG 示意图坐标，**不是经纬度**，不代表真实地理位置。

4. **使用限制。**
   以上内容仅用于**课堂教学演示**，不构成学术引用依据。如需在论文或作品中引用具体史实、
   日期与引文，请回到原始文献（鲁迅原著、年谱、权威传记）核对。

---

## 二、地图数据的说明（非常重要）

- 本模板使用的是一张 **SVG 示意地图**，地点位置是 `places.json` 中的
  **示意坐标 `x` / `y`**（分布在 `0 0 900 520` 的范围内）。
- 这些坐标**不是经纬度**，**不使用任何真实地理数据**，也不接入任何外部地图服务。
- 地图的作用只是把地点“摆开”，帮助理解地点之间的关系，**不具备地理定位的准确性**。

---

## 三、数据用途

- 数据仅用于**课堂教学演示**：演示如何使用 JSON 存放数据、如何用 JavaScript 读取并渲染。
- 不用于任何真实导航、地理分析或生产用途。

---

## 四、本课程对数据的简化

为了让零基础同学容易上手，本模板对数据做了如下简化：

- 只保留“地点”和“故事”两类数据，分别放在两个 JSON 数组里。
- 地点用两个数字 `x`、`y` 表示位置，省去一切地理投影、坐标系统换算等复杂内容。
- 故事用 `place_id` 关联地点、用 `order` 决定顺序，字段少、含义直观。
- 不涉及数据库、后端接口、地图服务授权等概念。

---

## 五、替换成你自己的文学故事时，请这样写来源说明

当你把示例内容换成自己的内容时，请在本文件中（或另建一份来源说明），
把你的数据来源写清楚。建议至少写明以下三点：

1. **资料来源**：内容来自哪本书、哪篇文献、哪个（权威）网站？
   如果是引用原文，请注明书名 / 篇名、作者、出版社 / 网址。
2. **整理方式**：你是如何整理的？（例如：摘录、概括、翻译、按时间排序……）
   哪些是你自己概括的，哪些是直接引用的。
3. **核对情况**：由谁核对、核对到什么程度，是否还存在未核实的部分。
   凡是**未核实**的内容，都应明确标注为“待核对”。

> 一句话原则：**写清“资料从哪来、怎么整理、谁核对过”**。
> 不确定的内容不要当成事实写，宁可标注“待核对”。
