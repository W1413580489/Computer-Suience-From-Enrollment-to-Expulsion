# 登录界面游戏化改造 — 方案文档

## 一、整体访问流程

```
访问 jnuxky.xyz
    │
    ├── 已登录用户 → 直接进入主页（跳过开屏和建号）
    │
    └── 未登录用户 → 开屏动画（终端启动风格）
                          │
                          ├── [跳过] → 进入主页（游客模式，无个性化）
                          │
                          └── 自动播放完毕 → 建号界面
                                                │
                                                ├── 填写昵称
                                                ├── 选择专业类别（软件/硬件/其他）
                                                ├── 选择年级（大一~大四）
                                                ├── 上传头像（可选，base64 存 localStorage）
                                                │
                                                └── 点击「建号」→ 身份工牌弹窗 → 进入主页
```

## 二、开屏动画（SplashScreen.vue）

### 通用行为
- 纯 CSS 动画 + 极简 JS（仅控制文字逐字输出和进度条填满）
- 无外部依赖，无 Canvas/WebGL，无密集计算，适配 1.8G 内存服务器
- 动画时长约 3-4 秒，播放完毕后自动跳转建号界面
- 右下角显示「跳过 >>」链接，点击直接进入建号界面
- 点击屏幕任意处可加速动画（立即跳转）

### 夜间模式（ZZZ 绳网系统风格）
| 视觉元素 | 实现方式 |
|----------|----------|
| 背景 | 纯黑底 + 深色网格线（CSS `background-image` 重复网格） |
| 主色调 | 琥珀黄 `#FFD93D`（主色）、霓虹青 `#00F0FF`（辅色点缀） |
| 顶部 LOGO | 绳网风格 "TERMINAL CONNECT" 标题，琥珀黄发光，带扫描线闪烁 |
| 文字输出 | 逐行打字机效果：<br>1. 「连接终端中枢...」<br>2. 「正在验证身份凭证...」<br>3. 「同步角色数据...」<br>4. 「连接成功。欢迎回来。」 |

## 四、身份工牌（IdentityBadge.vue）

### 双模式设计
`IdentityBadge` 组件支持两种模式，通过 `mode` prop 控制：

| 模式 | 触发场景 | 底部按钮 |
|------|----------|----------|
| `create` | 首次建号完成时 | 「确认，进入主页」→ 关闭弹窗，跳转首页 |
| `view` | 右上角用户头像点击 | 「确认，关闭」→ 关闭弹窗 + 「切换身份」→ 跳转建号界面 |

### 通用行为
- 夜间模式：`ZModal` 全屏展示 | 日间模式：自定义弹窗
- **仅首次建号时自动弹出**（`create` 模式），已登录用户再次访问直接进入主页
- 已登录用户点击右上角头像 → 弹出 `view` 模式工牌
- 展示信息：昵称、年级、专业类别、头像（若有）、UID、建号日期
- `view` 模式底部增加「切换身份」按钮，点击跳转 `/login` 建号界面

## 五、数据存储（userStore.ts — 扩展）

```typescript
interface UserProfile {
  nickname: string;
  grade: 1 | 2 | 3 | 4;
  major: 'software' | 'hardware' | 'other';
  avatar?: string;  // base64 图片数据，新增
  uid: string;      // 唯一编号，新增，格式 XKZ-YYYYMMDD-XXXX
  createdAt: string; // 建号日期，新增
}
```

- `avatar`：用户上传的头像图片，转为 base64 后存 localStorage
- `uid`：自动生成，格式 `XKZ-YYYYMMDD-XXXX`（4 位随机十六进制）
- `createdAt`：建号时的日期字符串

## 八、技术要点

### 内存优化
- 开屏动画全部使用 CSS `@keyframes` + `animation`，无 JS 定时器密集循环
- 文字打字效果使用 JS `setInterval` 逐字追加，单个 interval 即可，不占内存
- 头像图片 base64 通常 < 500KB，localStorage 足够存储
- 无 Canvas、WebGL、外部动画库依赖

### 主题切换
- 复用现有 `data-theme` 属性（`zzz` / `ak`）
- 所有新增组件通过 `:class` 绑定 `theme.isZzz ? 'theme-zzz' : 'theme-ak'` 切换样式
- zenless-ui 组件仅用于夜间模式

### 头像上传
- 使用 `<input type="file" accept="image/*">`
- 通过 `FileReader.readAsDataURL` 转为 base64
- 存到 `userStore.user.avatar`
- localStorage 同步保存
- 提供删除/更换头像按钮
