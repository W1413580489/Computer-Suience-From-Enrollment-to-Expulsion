# AI 项目导师 · 学生使用手册

> 适用对象：零基础同学。跟着做，每一步都有说明。
> 网址：**https://jnuxky.xyz**（建议用电脑浏览器打开，手机只能看，不方便操作）

---

## 这个网站是干嘛的？

一句话：**AI 带你做完一个真项目，做完还帮你把"项目经历"写成简历里能直接用的那段话。**

整个流程只有 5 步：

```
① 准备钥匙 → ② 选课程和任务 → ③ 跟着 AI 做项目 → ④ 提交验收 → ⑤ 拿简历描述 + 面试自检
```

不用租服务器、不用买域名、不用部署上线——**这些统统不需要**。项目在你自己电脑上能跑起来就算数。

## 第 0 步：准备一把"钥匙"（DeepSeek API Key）

AI 导师背后用的是 DeepSeek 大模型，你需要自己的 Key（就像一把钥匙），费用由你自己的账户承担，用多少花多少。

1. 打开 **https://platform.deepseek.com**，用手机号注册一个账号
2. 登录后，点左侧「**API Keys**」→「**创建 API key**」
3. 随便起个名字（比如"课程用"），点创建
4. 页面会显示一串 `sk-` 开头的字符——**立刻复制保存**（这个页面只显示一次，关掉就再也看不到了）
5. 充值：点左侧「充值」，**充 10 块钱就够用很久**（这门课全程大概花不了几块钱）

> ⚠️ Key 就是密码：不要发给任何人、不要贴到公开的代码里、不要传到 GitHub 上。泄簀了立刻回这个页面删掉重建。

## 第 1 步：登录并进入 AI 导师

1. 打开 **https://jnuxky.xyz**
2. 第一次进入会让你填：**昵称 / 年级 / 专业类**（只存在你自己浏览器里，随便填个昵称就行，也可以点"游客模式"跳过）
3. 在顶部导航点「**AI 导师**」（或"AI 项目导师"）进入

## 第 2 步：选课程、选任务

进入后是一个课程选择界面（左右转动选课）：

- **课程一：套壳聊天机器人**（十几分钟做一个网页聊天机器人）——**零基础从这门开始**
- 课程二：GitHub 项目分析 Agent（有了一课基础再玩）

选好课程后，回到对话界面，看**左侧栏**：

1. **选任务**：在下拉框里按顺序选（001 → 002 → …，做完一个再做下一个）
2. **填 API Key**：在侧栏找到 `sk-...` 输入框，把第 0 步保存的 Key 粘贴进去（存在你自己浏览器里，不会上传）
3. **填仓库地址**（选填）：如果你把代码传到了 GitHub，把仓库链接粘贴进去（形如 `https://github.com/你的用户名/仓库名`）。AI 能自动读你的代码，验收更准

> 💡 注意：仓库要设成 **Public（公开）**，AI 才读得到。GitHub 仓库页面 → Settings → 拉到底 Danger Zone → Change visibility。

---

## 第 3 步：跟着 AI 做项目

**直接在底部输入框打字就行，像聊天一样。** 不用选什么"模式"——AI 会自动判断你现在的处境：

| 你说的话 | AI 自动做的事 |
|---|---|
| "我不知道从哪开始" | 帮你把任务**拆解**成小步骤 |
| "后端写好了，下一步呢" | 告诉你**当前只管做哪一步**，推进进度 |
| （粘贴一段报错） | 进入**调试**状态，一步步带定位问题 |

几个实用技巧：

- **报错直接整个复制粘贴**给 AI，比描述"跑不起来"有用一百倍
- AI 的回复下方有一个小提示标签（拆解中 / 推进中 / 调试中），告诉你它现在在干嘛
- AI 是**引导为主**，不会一上来直接甩完整代码——这是故意的，抄来的代码面试一问就露馅
- 每完成一步，就跟 AI 说一声"这步做完了"，它会带你走下一步

---

## 第 4 步：提交验收（任务做完后）

觉得任务做完了？看左侧栏的「**提交验收**」区域：

1. 点「**展开验收材料（选填）**」，按情况填：
   - **在线部署地址**：没有就空着，**不填不扣分**（这是加分项）
   - **关键代码片段**：把核心代码粘贴进来（比如 main.py 的内容）
   - **自述说明**：用几句话写清楚——**怎么运行它**（写明启动命令，比如 `uvicorn main:app --port 8000`）、数据怎么流的、遇到过什么问题
2. 点「**⚖ 提交验收**」按钮

**AI 评审的判定规则**（透明公开，不是黑箱）：

- **运行证据三选一**，有任意一个就行：
  - ① 自述或 README 里写了启动命令（本地能复现）
  - ② 你的 GitHub 仓库有 CI 且测试通过（不懂 CI 没关系，没有就跳过）
  - ③ 在线部署地址（自愿提供）
- 每条验收标准独立判 **PASS（通过）/ FAIL（不达标）/ NEED_REVIEW（证据不够）**
- 总分 = 按重要度加权算出来的，**同样的证据永远得同样的分**（不会这次 80 下次 60）
- 10 分钟内用同样材料重复提交，会直接秒回上次结果（不重复扣你的 API 额度）

**看懂评审结果**：

- ✅ 全部 PASS → 恭喜，跳到第 5 步
- ⚠️ 有 NEED_REVIEW → 看"下一步"提示，补对应证据再提交（比如提示缺运行证据，就在自述里写上启动命令）
- ❌ 有 FAIL → 按每条的"依据"和理由修改代码，改好重新提交。**对话记录都在，直接问 AI "这条 FAIL 怎么改" 就行**

---

## 第 5 步：拿你的成果（重点！）

验收通过的那一刻，聊天里会自动出现一张**成果卡**，里面有两样东西：

### ① 可写进简历的项目经历（一段话 + 复制按钮）

AI 根据你的真实验收数据生成，比如：

> 独立完成「套壳聊天机器人」项目：写后端接口、写前端页面、联调跑通、提交成果验收。技术栈为全栈项目开发。项目通过 11/11 项自动验收，GitHub Actions 测试通过。代码仓库与运行说明可公开验证（https://github.com/你的用户名/仓库名）。

点「**复制**」，整段粘贴进简历即可。每通过一个任务，这段话会自动累积更新。

### ② 面试自检（不判分，纯粹帮你练）

2 道面试官风格的问题，比如"如果要多轮对话记忆，你会怎么改？"

用法：

1. 先自己在框里**打一遍答案**（或心里说一遍）
2. 点「💡 看提示」——想不出来再看
3. 点「✅ 对参考答案」——对照锚点看自己答得全不全
4. 两题都对完 → 提示"**这段项目经历可以放心写进简历了**"

> 为什么要有这一步？因为面试官一定会问你项目的细节。答不上来的部分，回到第 3 步问 AI 把它搞懂——**能讲清楚的项目才是你的项目**。
>
> 放心：这一步**不打分、不计入验收结果**，答错了没有任何惩罚。

## 常见问题（FAQ）

**Q：评审一直 NEED_REVIEW，说我缺运行证据？**
在"自述说明"里写清楚怎么启动。最低要求是一行启动命令，例如 Python 后端写 `uvicorn main:app --port 8000`，前端写"浏览器直接打开 index.html"。写了还不行就把启动命令贴给 AI 确认能跑。

**Q：提示 API Key 无效？**
回 platform.deepseek.com 检查：① Key 是否复制完整（sk- 开头）；② 账户是否有余额。

**Q：能直接让 AI 把整个项目写完吗？**
AI 会拒绝在第一步就甩完整代码（引导你分步做）。这不是bug——直接抄的项目，验收时"讲清数据流向"那条你过不了，面试更是必挂。

**Q：我的评审分会不会跟别人比？**
评审只对比"你提交的证据"和"验收标准"，和任何人无关。

**Q：换电脑 / 清了浏览器缓存，数据没了？**
会话记录和已通过的进度存在浏览器本地。换设备后重新登录、重填 Key 即可；已通过的任务重新快速验收一次就行（材料没变会秒回结果）。

**Q：需要部署上线吗？**
**不需要。** 部署是自愿的加分项，不做完全不影响通过。
